# Report exhibits

Drop the three final exhibit images here using exactly these filenames — the
sections are already wired to them, so no code change is needed:

| File                      | Section                        |
|---------------------------|--------------------------------|
| `ecosystem-matrix.webp`   | Ecosystem Matrix               |
| `positioning-matrix.webp` | Competitive Positioning Matrix |
| `market-share.webp`       | Market Share                   |

Until a file exists the section falls back to the empty reserved frame — no
broken-image icon, no layout shift. Once it exists the image renders with the
"Expand" badge and opens full-screen on click.

Different filenames or a different format (.png/.jpg) are fine — just say so and
the `imageSrc` on that section gets updated.

`imageAlt` is currently the section title as a placeholder; replace it with a
real description of what each exhibit shows.
